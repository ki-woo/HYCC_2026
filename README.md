## 사용된 기술

### Perlin Noise
**Used** : 랜덤한 맵의 지형을 만들 때 사용되었습니다. (mapGenerator.cs)

**Description** :
- 정해진 구역에서 일정한 간격마다 랜덤한 기울기 값을 설정해줍니다.

- 각 간격 끝점에서 정해진 기울기 값을 이용하여 그 사이를 보간합니다.

- 이렇게 만들어진 노이즈를 옥타브라고 합니다.

- 높이 배율(y축으로 몇배 늘린 건지)과 간격을 달리하며 여러 옥타브를 만듧니다. \
보통 $S^n$ 비율로 옥타브를 조절합니다. \
\
**게임에서 사용된 옥타브**
    - Octave1 : interval 25, scale 25
    - Octave2 : interval 5, scale 5

- 이렇게 만들어진 각 옥타브들을 전부 더해서 최종 노이즈를 만듧니다.

---

### Interpolation (보간)
**Used** : 노이즈를 생성할 때 떨어진 점 사이에 다른 점을 추가로 그리기 위해 사용되었습니다. (mapGenerator.cs)

**Description** :
- 보간할 각 끝점의 위치를 잡습니다. \
게임에서는 각 끝점의 높이를 0으로 설정하고 그 대신 기울기를 사용했습니다.

- 각 간격 끝점에서 정해진 값들을 이용해서 그 사이를 보간합니다. \
게임에서 보간함수는 삼차함수를 응용하여 만들었습니다. \
\
$y = (y'_1 + y'_2)t^3 - (2y'_1 + y'_2)t^2 + y'_1t \quad (0 \leq t < 1)$ \
\
간격이 1이고 각 끝점 좌표가 $y_1 = y_2 = 0$, 기울기가 $y'_1$, $y'_2$인 보간함수. \
보간 함수를 간단히 만들기 위해 각 점의 간격이 1이라 가정하고 나중에 늘렸습니다.

---

### Mesh
**Used** : 만들어진 노이즈에 질감을 넣기 위해 사용되었습니다. (mapGenerator.cs)

**Description** :
- 생성된 노이즈를 각 버텍스(꼭짓점)으로 설정합니다.

- 랜더링을 위해 각 버텍스를 삼각형으로 이어줍니다. \
이때 버텍스는 오른손법칙에 따라 이어줍니다. \
삼각형의 꼭짓점이 이어지는 순서가 삼각형이 보여지는 방향을 설정합니다. (외적)

- 이미지 파일을 넣기 위해 각 버텍스에 대응되는 점을 이미지 파일 위에 놓아 UV를 만들어 줍니다.

- 최종적으로 메쉬에 머테리얼을 설정합니다.

## 물리
각 행성의 물리황경을 구현하는 데 있어 유니티 내부 물리엔진을 이용하려 했으나 유니티 내부에 항력을 계산하는 내부 엔진이 없었습니다. 그래서 항력은 자체적으로 계산하는 코드를 따로 만들었습니다.

- **항력공식** : $F_d = -\frac{1}{2}ρ v^2 A C_D \hat{v}$
    - $F_d$ : 항력
    - $ρ$ : 대기밀도
    - $v$ : 물체와 유체의 상대속도
    - $A$ : 기준면적 (유체가 불어오는 방향에서 보이는 단면적)
    - $C_D$ : 항력계수
    - $\hat{v}$ : 물체의 유체에 대한 상대속도 방향 (단위벡터)

항력을 구할 떄 공식이 너무 복잡해지지 않도록 물체를 크기가 일정한 구체로 가정함으로써 항력계수와 기준면적을 상수로 만들었습니다.

- $A = \pi r^2$
- $C_D = 0.47$

## 개발 중 어려움
- **UV 깨짐** \
UV 설정 중에 이미지가 연속적으로 이어지지 않고 끝에서 늘어지는 현상이 있었다. 처음에는 코드 문제로 생각해서 코드를 바꿔가며 실행해 봤는데 문제가 해결되지 않아서 시간이 꽤 걸렸다. \
GPT에게 물어봐가며 설정값들을 하나씩 살펴본 결과 이미지 파일 설정이 타일링이 안 되도록 설정되어있어 UV가 연속되지 않고 하나만 생성한 채로 끝나 UV가 깨진 것이었다. 그래서 이미지 설정값을 재설정하여 문제를 해결했다.

- **UI Fade in/out 실행 안됨** \
게임에서 씬을 시작하거나 끝날 때 씬 전환효과로 페이드 인/아웃 효과를 넣으려고 UI Toolkit의 애니메이션 효과를 사용하려 했으나 툴을 다루는 데 미숙하여 제대로 적용되지 않았다. \
그래서 페이드 설정값을 코드로 하나씩 수정하는 방식으로 페이드를 적용하는 방식으로 문제를 해결했다.
